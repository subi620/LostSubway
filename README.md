# 🚇 로스트인지하철 (LOST IN SUBWAY)

**로스트인지하철**은 지하철에서 잃어버린 물건을 경찰청 LOST112 습득물 데이터에서 역, 물품 종류, 기간으로 찾아보는 웹사이트입니다. 검색 결과에서 현재 보관 장소와 연락처를 확인하고, 방문 전에 필요한 정보를 살펴볼 수 있습니다.

---

## 🚀 프로젝트 개요

지하철에서 습득한 물건은 역에서 보관하다가 유실물센터로 옮겨질 수 있습니다. 이때 보관 장소만으로 검색하면 처음 물건을 잃어버린 역의 결과를 놓치기 쉽습니다. 로스트인지하철은 LOST112 데이터를 받아 역과 유실물센터의 정보를 연결하고, **처음 습득한 역을 기준으로 찾을 수 있도록** 돕습니다.

## 🛠 기술 스택

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python 
- **Data:** 경찰청 LOST112 공공데이터 API, SQLite, Turso DB

## ✨ 주요 기능

### 1. 역 · 물품 · 기간별 검색

- 역 이름 자동완성과 노선 배지를 제공합니다.
- 지갑·카드, 휴대폰, 가방 등 물품 종류와 최근 3·7·14·30일 기간으로 결과를 좁힐 수 있습니다.
- 검색 결과가 부족하면 비슷한 역 이름, 노선 전체, 더 긴 기간으로 범위를 넓히는 선택지를 보여줍니다.

### 2. 옮겨진 물건의 원래 습득역 찾기

- 역과 유실물센터의 보관장소 표기를 구분합니다.
- 기관번호와 상세 정보의 습득 장소를 활용해 센터로 옮겨진 물건도 원래 습득역으로 검색할 수 있게 합니다. 원래 역을 확인할 수 없는 물건은 임의로 단정하지 않습니다.

### 3. 찾으러 가기 정보

- 물건의 보관 상태, 보관 장소, 연락처, 습득일과 상세 특이사항을 확인할 수 있습니다.
- 방문 전에 보관 장소에 연락해 확인할 사항을 안내합니다.


## 📌 이용 범위

- 현재는 **포털기관 습득물정보**를 사용하며, 경찰서 보관 습득물은 검색 대상에 포함되지 않습니다.
