# 로스트인지하철 (LOST IN SUBWAY)

지하철에서 잃어버린 물건을 **경찰청 LOST112 공식 습득물 데이터**에서 역 · 물품 · 기간으로 찾는 웹사이트입니다.
디자인은 캔버스 「지하철 분실물 찾기 — 예시 디자인」의 화면 3장(검색 → 결과 → 찾으러 가기)을 따릅니다.

## 실행

```bash
python server.py
```

브라우저에서 http://127.0.0.1:5600 을 엽니다. Python 3.10 이상, 설치할 패키지는 없습니다(표준 라이브러리만 사용).

- 처음 켜면 최근 30일치 습득물을 받아 `data/lost112.db` 에 저장합니다 (약 2~3분, API 30회 호출).
  받는 동안에도 검색은 되고, 첫 화면 아래에 진행 상황이 보입니다.
- 이후 60분마다 최근 5일치를, 하루 한 번 30일치를 다시 받습니다.
- 끄려면 `Ctrl+C`.

## 키 설정

`.env` 의 `LOST112_SERVICE_KEY=` 뒤에 data.go.kr **일반 인증키(Decoding)** 를 넣습니다.
필요한 API는 **경찰청_포털기관 습득물정보 조회 서비스** 하나입니다.

> 이 PC에서는 `.env` 를 더블클릭하면 보안 프로그램(AnySign)이 암호를 묻습니다. 메모장이나 VS Code로 여세요.

키 확인: `python tools/probe_api.py`

## 어떻게 찾나

| 확인한 사실 (실제 API 기준) | 그래서 |
|---|---|
| 응답은 XML만, 한 번에 5,000건까지, 결과가 날짜순이 아님 | 검색마다 API를 부르지 않고, 하루 단위로 전부 받아 SQLite에서 검색 |
| 역 보관분은 `사당역(2호선)`, 센터 보관분은 `시청유실물센터` 처럼 표기 | 보관장소를 해석해 역 · 노선 · 센터를 나눔 |
| 역 물건은 며칠 안에 노선별 유실물센터로 옮겨짐 | 관리번호(atcId) 앞 8자리 = 처음 등록한 기관 → **센터 물건도 원래 습득역으로 검색** (센터 보관분의 약 90%) |
| 상세 특이사항에 `강남역(2호선)에서는 … 습득` 문구 | 상세를 볼 때 원래 역을 한 번 더 확인 · 보정 |

서울교통공사 유실물센터: 시청(1·2호선), 충무로(3·4호선), 왕십리(5·8호선), 태릉(6·7호선) — 서울시 안내 기준.

## 폴더

```
server.py            웹서버 + /api/*
lost112/
  client.py          data.go.kr 호출 · XML 해석 · 오류 메시지
  sync.py            백그라운드 동기화 (python -m lost112.sync 30 으로 단독 실행 가능)
  store.py           SQLite 저장 · 검색 · 원래 습득역 연결
  places.py          보관장소 해석, 노선 색/배지, 물품 6분류
  config.py          .env 읽기
public/              화면 (index.html, app.css, app.js)
tools/               probe_api.py(키 확인) · inspect_db.py(DB 통계) · smoke_api.py(API 점검)
data/lost112.db      자동 생성 (지워도 다시 받음)
```

## API (로컬)

| 경로 | 설명 |
|---|---|
| `/api/status` | 동기화 상태, 저장 건수 |
| `/api/stations?q=강남` | 역 자동완성 (노선 배지 포함) |
| `/api/lines` | '열차 안' 노선 목록 |
| `/api/search?station=강남&cat=wallet&days=14` | 검색 + 범위 넓히기 제안(+N건). `scope=keyword` / `scope=line&line=2호선` |
| `/api/details?ids=…` | 목록 앞쪽 보관상태 (상세 API, 6시간 캐시) |
| `/api/item?id=ATC:SN` | 찾으러 가기 화면 (보관상태 · 전화 · 습득 시각 · 특이사항) |

## 알아둘 점

- "못 찾으면 다시 확인"은 푸시 알림이 아닙니다. 결과 화면에서 [이 조건 저장]을 누르면 조건이 **그 브라우저(localStorage)** 에만 저장되고,
  첫 화면 '저장한 조건'에서 조건마다 새로 올라온 습득물 수를 보여줍니다(최대 5개). 다른 기기·브라우저, `127.0.0.1`과 `localhost`는 서로 공유되지 않습니다.
- 경찰서로 넘어간 물건(경찰청_습득물정보 조회 서비스)은 아직 포함하지 않습니다. 그 API를 활용신청하면 추가할 수 있습니다.
- 로컬(127.0.0.1)에서만 열리도록 되어 있습니다. 외부 공개는 별도 배포 작업이 필요합니다.
